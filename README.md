# Faktury – Koření od Havrana

Jednoduchá fakturace pro prodej koření. Běží v prohlížeči (GitHub Pages), nic se neinstaluje.

- **Nová faktura** – vyberete odběratele, položky z minulé faktury se načtou samy, změníte jen počty kusů. DPH, součty a zaokrouhlení se počítají automaticky. Číslo faktury = variabilní symbol, další číslo se nabídne samo.
- **Vystavené faktury** – přehled, tisk / PDF, úprava, „nová podle této“, označení zaplaceno.
- **Odběratelé** – každý má přiřazený ceník (např. Ceník Šimák nebo Základní ceník).
- **Ceníky** – ceny za kus bez DPH, dají se rovnou přepisovat.
- **Nastavení a záloha** – údaje dodavatele, splatnost, stažení a obnovení zálohy.

Data se ukládají jen v prohlížeči na tomto počítači. Pravidelně stahujte zálohu (Nastavení a záloha → Stáhnout zálohu).

Soubory se zálohou ani počáteční data (`*.json`) do repozitáře nenahrávejte – obsahují údaje odběratelů a ceny.
